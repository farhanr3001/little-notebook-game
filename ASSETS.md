# Asset provenance

All shipped illustration files are generated project assets; the user's reference images are not copied into the release. Generated illustrations were made with the built-in imagegen tool, not the API/CLI fallback. The final files live in `assets/` and are copied into the portable build.

- `characters.png`: original six-character transparent full-body sheet. Four female characters are retained from this sheet. The two initial male designs are replaced in selection by the expanded male sheet.
- `characters-men.png`: four youthful male characters matching the original style, with varied skin tones and short hairstyles.
- `characters-women.png`: two additional young female characters matching the original style, with darker skin tones.
- `radio.png`: the original Matcha radio, retained unchanged.
- `radio-rose.png`, `radio-sky.png`, `radio-lavender.png`, `radio-night.png`: palette edits of the original drawing made with the built-in image_gen tool. The control geometry, transparent background, cream speaker, gold stickers and green botanical details are preserved. Exact prompts are in `radio-palette-prompts.json` in the release and `tools/radio-palette-prompts.json` in the source workspace.
- `paper.png`: blank warm cream paper texture.
- `beach-resort.mp3`, `road-trip.mp3`, `look-on-the-bright-side.mp3`: **Beach Resort**, **Road Trip**, and **Look on the Bright Side** by **Purrple Cat**, downloaded directly from the artist's [Just Relax album](https://purrplecat.itch.io/just-relax). The artist offers the tracks for game use and requests credit. The album page lists CC BY-SA 4.0: https://creativecommons.org/licenses/by-sa/4.0/ . The tracks are unmodified. Retrieval script: `tools/download_music.py`.
- `typing.wav`, `click.wav`, `correct.wav`, `wrong.wav`, `finish.wav`: short game cues arranged from **Salamander Grand Piano** by **Alexander Holm** (CC BY 3.0, https://creativecommons.org/licenses/by/3.0/), distributed through the [Tone.js audio collection](https://tonejs.github.io/audio/). Source note: https://tonejs.github.io/audio/salamander/C4.mp3 . Changes: mono conversion, pitch resampling, trimming, gain adjustment, fades, and arranging notes into short cues via `tools/make_audio.py`. The original downloaded sample is kept in `tools/samples/piano-C4.mp3`.
- `LittleNotebook.ico`, `book-icon.png`: native vector book drawing from `src/BookIcon.cs`, rasterized by WPF into seven icon sizes. Embedded into the executable and used by the native window.
- `pets.png`: six transparent watercolor/pencil animal cutouts generated with the built-in imagegen tool for v0.3. Cat colours are separate sprites; explicit atlas crop boundaries and alpha trimming keep every animal centred and intact. Exact prompt below.
- Doodles, tracing outlines, stamps and new vocabulary pictures are native drawing code in `src/Art.cs` and `src/Doodles.cs`. Animal vocabulary uses the generated pet sprites where applicable.
- Fonts are Windows-installed Segoe Print and Segoe UI; no font files are redistributed.

## Offline speech — v0.3.2

- `assets/speech/*.wav`: 93 distinct current listening words synthesized locally with Kokoro-82M, voice **af_heart**, speed 0.96. PCM16 mono 24 kHz, normalized with short fades/padding. Mapping and generation provenance/model hashes are in `assets/speech/manifest.json` and `provenance.json`. Build script: `tools/make_speech.py`. Full-precision model was used for these prebuilt clips.
- English question narration: Kokoro v1.0 int8 ONNX, af_heart, generated on demand. Model and voice embeddings originate from the [kokoro-onnx model release](https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0). [Kokoro model card](https://huggingface.co/hexgrad/Kokoro-82M) and [voice descriptions](https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md). Kokoro weights use Apache 2.0; kokoro-onnx wrapper uses MIT.
- Arabic question narration: Piper **ar_JO-kareem-medium**, single Jordanian Arabic voice at 22,050 Hz. [Model files/card](https://huggingface.co/rhasspy/piper-voices/tree/main/ar/ar_JO/kareem/medium); the card is retained at `speech-runtime/models/MODEL_CARD`. Arabic diacritization comes from the Piper package's bundled tashkeel model. This is Arabic speech, not a Moroccan dialect voice.
- The portable helper bundles [CPython 3.12.10 for Windows x64](https://www.python.org/downloads/release/python-31210/) and isolated packages: kokoro-onnx 0.6.1, [Piper 1.4.2](https://github.com/OHF-Voice/piper1-gpl), ONNX Runtime 1.31.0, NumPy 2.5.4, SoundFile 0.14.0, phonemizer/eSpeak NG and their dependencies. Python LICENSE.txt, package metadata and included license files stay in `speech-runtime`. Piper/phonemizer/eSpeak components carry GPL terms; upstream source links and package notices are retained in THIRD_PARTY_NOTICES.md there. No system Python installation is modified.
- `tools/prepare_speech_runtime.py` assembles the private helper; `tools/speech_worker.py` is this project's UTF-8 JSON-lines worker. The native WPF process launches it without a visible console or network service. Generated narration lives in `data/speech-cache`, excluded from shareable archives. The main game remains native C#/WPF.
